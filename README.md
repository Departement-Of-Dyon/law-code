# Law of Code

**Article 1.** Code that works is law. Code that merely compiles is a draft.

**Article 2.** Every function shall do one thing. Functions doing three
things shall be brought before the Committee of Refactoring.

**Article 3.** Comments explain why, never what. The what is the code's
own confession.

**Article 4.** Dependencies are guests: welcome, but they do not pay rent
in compile time.
